# Gemini 独立搜索

在 SillyTavern（酒馆）里先让 Gemini 使用 Google 搜索，取得摘要和来源，再交给原来的正文模型继续回复。搜索与正文使用两次独立请求，正文保留角色卡和原有输出格式。

**当前版本：0.1.1 试用版。** 适配目标为 SillyTavern 1.17.0+ 的单人聊天与聊天补全连接。已核对 1.17.0 / 1.18.0 的流式转发源码，通过 19 项自动测试；浏览器模拟交接已验证，Google API 的实际联调仍待验证。

### 0.1.1 修复

修复正常搜索返回被误判为“没有收到 Google 原生流式数据”的问题。SillyTavern 的转发函数可能只转发数据，不保留 `Content-Type` 响应头。现在根据实际的 `data:` 分段读取内容，仍要求 Google 原生回答、完整结束标记和真实搜索来源。遇到这个报错的 0.1.0 用户，请在扩展管理器更新后刷新酒馆页面。

## 安装

1. 复制安装地址：

   ```text
   https://github.com/493945271w-create/Extension-GeminiSearchBridge
   ```

2. 打开酒馆的 **扩展 → 安装扩展**，粘贴地址并安装。
3. 刷新页面，在扩展设置中找到 **Gemini 独立搜索**。

仓库根目录直接包含 `manifest.json` 和 `index.js`，可以通过酒馆的扩展管理器安装。更新时使用扩展管理器的更新按钮，再刷新页面。卸载时先禁用扩展，再通过扩展管理器删除。

## 第一次使用

1. 在酒馆中配置好 **Google Vertex AI** 或 **Google AI Studio** 的连接与凭据，确认该连接可用。
2. 在扩展中选择搜索连接。模型栏留空时，沿用酒馆为该来源保存的模型；也可填写支持 Google Search 的 Gemini 模型 ID。
3. 输入搜索问题，点击 **搜索资料**，查看摘要、来源和实际查询词。
4. 点击 **交给下一次回复**，再在当前单人聊天发送消息。资料也可用于下一次重新生成、滑动或续写，只使用一次。

搜索示例：`查找某个角色在原作中的出场时间，列出可核对的来源。`

扩展启用时会关闭正文请求里的原生 Google 搜索。搜索结果作为本轮临时参考资料交给正文模型，不写入聊天消息或世界书。

## 自动搜索

**每次发送新消息前自动检索** 默认关闭。开启后，扩展会先搜索本次新消息，再发送正文请求。

- 搜索请求只包含搜索问题和填写的固定检索背景，不包含整份角色卡、世界书或历史聊天。
- 自动模式只处理单人聊天的新消息。重新生成、滑动、续写和无输入的提示词预览不会自动重新搜索。
- 自动搜索失败、被取消、没有来源或结果被截断时，本轮正文请求会停止，错误原因会显示在扩展面板。
- 扩展不会自动重试；请修正问题后重新发送。

## 连接与费用

扩展复用酒馆服务器保存的 Google 凭据。Vertex 的认证方式、区域和 Express 项目 ID 沿用酒馆设置。搜索模型可以独立指定，正文可以使用其他聊天补全来源。

Google Search 是 Gemini 的工具，因此每次搜索仍是一笔独立模型调用，可能产生模型和搜索费用；一次模型调用也可能执行多条搜索查询。用量与计费取决于 Google 账户和选用模型。

默认通过 Google 官方连接发送。可选的 **使用酒馆当前 Google 反代** 仅在当前主连接与搜索来源相同时生效。反代必须支持 Google 原生流式响应及来源信息；只返回 OpenAI 兼容格式的接口不能用于此搜索连接。

## 资料如何处理

- 只接受 Google 实际返回的网页来源信息 `groundingMetadata`，不把模型自行写出的链接当作搜索成功的依据。
- 读取 Google 原生流式响应，提取摘要和来源，跳过标记为 `thought` 的思考内容。
- 来源与摘要按普通文本显示；Google 搜索建议组件在隔离页面中显示。
- 临时资料以 User、聊天末尾深度 0 的位置加入本轮提示词，并参与酒馆原有的字数预算。
- 外部文本中的酒馆双花括号宏会失活，避免被当成变量操作。
- 交给正文模型的资料包最多包含摘要前 8000 字符，以及按长度预算选取的最多 8 个来源。
- 搜索结果仅保存在当前页面内存中；切换聊天或刷新即清空。交接的资料会随正文 API 请求发送给正文模型服务商。

## 兼容性与限制

- Google 是否实际调用搜索由上游决定。扩展要求结果带有可核验来源，不能保证每个问题都能搜到资料。
- 搜索请求中的思考字段会被过滤。正文模型是否思考、是否显示推理，仍由正文模型与酒馆的推理设置决定。
- 关闭正文联网仅控制酒馆请求字段及显式 Google 搜索工具；自行联网的中转或 `:online` 型号不在这个控制范围内。
- 当前支持单人聊天和聊天补全主连接。群聊、文本补全、移动端真实酒馆、第三方反代，以及与其他自动搜索扩展同时使用，尚未验证。
- Google 搜索不访问电脑上的本地资料库；本地检索需要另外接入相应服务。

## 开发与验证

代码使用浏览器原生 JavaScript，无需编译。安装 Node.js 20 或更新版本后，在仓库目录运行：

```sh
npm test
```

测试使用模拟数据，不调用 Google API。覆盖搜索请求隔离、流式读取、来源校验、思考字段过滤、临时资料清理、跨聊天取消、自动搜索失败时停止正文，以及扩展启停清理。

真实酒馆验证仍需完成：扩展管理器安装、页面刷新后的加载、设置保存、一次真实搜索与来源显示、资料交接、取消、切换聊天和禁用清理。
